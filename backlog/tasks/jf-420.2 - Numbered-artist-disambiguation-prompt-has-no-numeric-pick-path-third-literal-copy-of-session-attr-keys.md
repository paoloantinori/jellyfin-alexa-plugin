## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Code-review finding (2026-08-31, high effort) on the JF-420 ambiguous branch. PlayArtistSongsIntentHandler.cs:460.

DEFECT (two parts):
1. The ambiguous branch speaks a numbered 'which one?' prompt ('Ho trovato piu artisti: 1. P!nk, 2. Pink Floyd. Quale?') but stores plain yes/no disambiguation state whose only consumers are YesIntentHandler (plays matches[0]) and NoIntentHandler (AskNextMatch). A user answering the question as asked ('due' / 'Pink Floyd') falls to general NLU/Fallback; the second artist is reachable only via an unadvertised 'no'.
2. The hand-rolled attribute dictionary in this branch bypasses DisambiguationHelper's constants, making a third literal copy of the session-attribute keys (future renames break the round-trip silently).

FIX SHAPE: decide ONE interaction and make prompt + state + consumers consistent. Numeric pick requires model samples for numbers on the follow-up (check what JF-21/JF-178 disambiguation already supports before inventing a new flow); the yes/no reword is the smaller change ('Ho trovato piu artisti, il primo e P!nk. Va bene?' style). Either way, route the attribute keys through DisambiguationHelper's single definition.

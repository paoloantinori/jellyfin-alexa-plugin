Announcements
Control what the skill speaks aloud.
Speak the content title when resuming playback. Disable for a briefer response with long titles.
Speak the content title ("Now playing X") when content is launched. Disable for silent launches. Per-user overrides take precedence.
Also speak the track name when music starts (songs/albums/artists). Off by default for fast, silent music starts; turn on if you want every track announced. Example: when on, the skill says "Now playing [song name]" before playing. Per-user overrides take precedence.
When a music request finds no song but an album or artist matches instead (or an artist request is served a matching song), say which one is playing before playback starts. Example: "play abbey road" with no song by that name plays the album and says "I found the album Abbey Road." When off, the substitution still plays but starts silently.
When paused, speak the current playback position. Example: "Paused at 2:15 of 4:30". Requires Seek Controls to be enabled. When off, pause is silent.

Cache Settings
Control disk cache for generated video-audio MP4 files. Cached files let subsequent plays start instantly without ffmpeg re-encoding.
Disk space for Echo Show album-art video files. When a song plays on a screen-equipped device, the plugin generates an MP4 with album art so the display stays active. Audio-only devices don't use this cache. Oldest files are evicted when the limit is exceeded. Default: 2048 (2 GB).

Custom Interaction Model & Catalog
Deploy a custom interaction model to override the built-in Alexa NLU model. The interaction model defines how Alexa interprets your voice commands — most users should leave this off.
Replace the built-in voice command model with a custom one from a URL. Use this to add or change the phrases Alexa recognizes for a locale.
URL to a custom interaction model JSON file.
"Deploy Model" and "Restore Default" apply to the selected locale only. "Rebuild Selected Locale" redeploys the embedded model for that locale; "Rebuild All Locales" redeploys every locale's model (one build each). Model builds take 15-30 seconds per locale.
Comma-separated locale codes for catalog sync beyond it-IT (always synced). Adds phonetic synonyms for non-English names so Alexa recognizes accented speech. Use * for all active locales. Each locale adds ~7s to sync time.
Mood Overrides
Add custom moods that map to Jellyfin genres. One per line as mood: genre1, genre2 (e.g. coding: electronic, ambient). The handler resolves these immediately; run "Rebuild Selected Locale" (Custom Interaction Model above) afterwards so Alexa recognizes the new mood words one-shot.
Leave a line's genres empty to skip it. Mood words over 140 characters are ignored (Alexa slot-value limit). Avoid mood words that match artist or genre names (e.g. "jazz", "nirvana") — Alexa may route those queries to mood music instead of the artist.
